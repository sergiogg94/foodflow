## How decisions are made here

- One ADR per independent decision, written by the **architect** agent (`/architect`).
- Files: `docs/adr/YYYY-MM-DD_<decision-slug>.md`
- An approved ADR is never contradicted silently — it is superseded explicitly by a new ADR that references it.
- Implementation follows the approved ADR exactly; deviations are blocking findings, not improvements.

_The architect agent updates this index whenever a new ADR is approved._
